# データソース

「衆議院選挙で、得た票はどれだけ議席になったか」のデータソースと、データ層の設計方針。
調査日: 2026-09-26。

## 1. 結論

一次情報源は総務省「衆議院議員総選挙・最高裁判所裁判官国民審査結果調」（兄弟サイトと同じ）。
このサイトは結果調を読み直さない。兄弟サイト2つが結果調から読んで突き合わせた配信データを、党名でつなぐ。

| 値 | 読み元 | 回 |
| --- | --- | --- |
| 得票数・有効投票数（全国、小選挙区・比例代表） | [election-shugiin-timeseries](https://github.com/visualizing-jp/election-shugiin-timeseries) の `public/data/era.json` | 第41〜51回 |
| 当選人数（全国、小選挙区・比例代表） | [shugiin-candidates](https://github.com/visualizing-jp/shugiin-candidates) の `public/data/national.json`（当選者の新前元 × 男女の和） | 第44〜51回 |
| 当選人数（第41〜43回） | [第49回確定結果調](https://www.soumu.go.jp/main_content/000930924.pdf) pp.26–27「党派別当選人数の推移」の手起こし（`data/seats-41-43.json`） | 第41〜43回 |
| 党の色相 | election-shugiin-timeseries の `public/data/palette.json` | — |

範囲は小選挙区比例代表並立制の第41回（1996年）から。第40回までは中選挙区制で、得票と議席の関係を同じ尺度で比べられない。

出典表記: 総務省「衆議院議員総選挙・最高裁判所裁判官国民審査結果調」。

### 確定と速報

兄弟サイトと同じく、確定結果が公表されていない第50・51回を「速報」とする。

## 2. 取得（`npm run fetch`）

兄弟サイトの GitHub リポジトリ（main）から、上の配信データを `data/sibling/{timeseries,candidates}/` に写す。毎回取り直して上書きする。
兄弟サイトのデータや配色が変わったら取り直し、`npm run verify && npm run data` を通す。

## 3. 第41〜43回の手起こし

兄弟サイト shugiin-candidates は第44回からなので、第41〜43回の議席は確定結果調の推移表から起こした。

- 推移表は党名を略記し、前の回の見出しを引き継ぐ列がある。列は数値の右端の位置で決め、見出しの位置と照らした。
- 略記は次の正式名称に戻した（兄弟サイト election-shugiin-timeseries の第41〜43回と同じ）: 自民→自由民主党、社民→社会民主党、新進→新進党、民主→民主党、民改連→民主改革連合、さきがけ→新党さきがけ、共産→日本共産党、公明→公明党、自由→自由党、保守→保守党、無の会→無所属の会、自連→自由連合。保守新党は表に正式名称で載っている。
- 第41回の新党さきがけの列には見出しがなく、第40回の「さきがけ」の見出しを引き継ぐ（小選挙区 2・比例代表 0）。その左の列が「民改連」（小選挙区 1・比例代表 0）。
- 「－」（比例代表で名簿がない党）は持たない。0 は届出があって当選のない党。
- どの回・制度も、党の和が推移表の「計」（定数）と一致する。

## 4. 読み方の決まり

- 党名は兄弟サイトと同じ文字列でつなぐ（各回の届出名称のまま）。別の回の同名・後継の党はつながない。
- 得票率 = 党の得票数 ÷ 有効投票数。議席率 = 党の当選人数 ÷ 定数。差 = 議席率 − 得票率。
- 得票の表に届出のない党は、その回・制度では null（得票も議席も持たない）。届出があって当選のない党の議席は 0。
- 兄弟サイト shugiin-candidates の当選人数の表は、その回に候補のない党も 0 で並べるので、議席 0 で得票がない党は読まない。
- ずれの大きさは Gallagher の最小二乗指数 √(½ Σ(得票率 − 議席率)²)（Gallagher, M. 1991. Proportionality, disproportionality and electoral systems. *Electoral Studies* 10(1), 33–51）。党ごとに数え、諸派・無所属はそれぞれ1つの党とみなす。画面で計算する。

## 5. 突き合わせ（`npm run verify`）

- 議席の党が、どれも同じ回・同じ制度の得票の表にある（党名が同じ文字列でつながる）。
- 制度ごとの議席の和 = 定数。
- 党の得票の和 ≤ 有効投票数。

## 6. 配信データ

`npm run data` が `data/sibling/` と `data/seats-41-43.json` だけを入力に、`public/data/` に書き出す。

| ファイル | 次元 | 値 |
| --- | --- | --- |
| `era.json` | 制度 × 党 × 回 | 得票数・議席数、有効投票数 |
| `palette.json` | 党 | 色相 |
